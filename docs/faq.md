# Frequently asked questions

## Can I use these scripts in production?

The repository has local syntax checks and selected offline tests, but no live validation for the product releases described here. Some historical examples are incomplete or need API adapters. Check the [script status](script_status.md) and [version scope](compatibility.md) for the file you plan to use, then test it against your own release and permissions before operational use.

## Where should I report a problem?

Open an issue in this repository with the script path, product and module versions, the command you ran, and a sanitized error. See the [contribution guide](../CONTRIBUTING.md). Do not include credentials or customer data.
