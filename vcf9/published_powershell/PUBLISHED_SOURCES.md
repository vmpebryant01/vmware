# Published sources for 30 VCF 9.1.1 PowerShell reports

By Paul Bryant

Each report is newly written, with selected CSV fields and the current vendor API endpoint shown below. No third-party source code was copied. These are related published reporting patterns and API examples, not evidence that the new report itself works in a live site.

**T** means the source project states it was tested on earlier product releases. The project-level claim does not establish a live run for the linked function or the VCF 9.1.1 adaptation. The [psNSXT project](https://psnsxt.github.io/psNSXT/) states testing on NSX-T 2.4.x, 2.5.x, and 3.0.x. The [AsBuiltReport VMware SRM project](https://github.com/AsBuiltReport/AsBuiltReport.VMware.SRM) states testing on SRM 8.3 through 8.7.

**P** means an official published function or API example exists, but I found no documented live run for that individual reference. [PowerValidatedSolutions](https://github.com/vmware/power-validated-solutions-for-cloud-foundation) and [PowerVCF](https://github.com/vmware/powershell-module-for-vmware-cloud-foundation) are official published modules. Where no matching function was found, the Broadcom API page is the source example. Published modules for earlier VCF releases are not a compatibility guarantee for VCF 9.1.1.

**All 30 new reports: offline checked only; live VCF 9.1.1 compatibility unverified.** The source reference may use a different API generation or a wider report scope.
