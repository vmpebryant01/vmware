# Security policy

Author: Paul Bryant

These scripts are examples. No version has been validated for production use, and live behavior depends on the installed VMware product and module versions. See [historical version scope](docs/compatibility.md) and [script status](docs/script_status.md).

If you find a security problem, use GitHub's private vulnerability reporting for this repository when available. If that option is unavailable, open a public issue that asks for a private contact method without including exploit details, credentials, or customer data. The maintainer will coordinate a private report.

Do not put live credentials in `.env.example` files, source, tests, logs, or issue reports. Revoke and replace any credential that was committed or disclosed.
