# Site Recovery Automation

Examples use SRM 8.x and pre-VCF-9 Live Site Recovery 9.0.2.x concepts with the VMware.PowerCLI 13.x family. The Live Site Recovery 9.0 version number is independent of VCF 9. Many integrations are incomplete and stop before producing operational results. See [historical version scope](../docs/compatibility.md) and the root README for limitations and setup.
